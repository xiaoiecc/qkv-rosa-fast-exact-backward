# 性能与精度实测报告

[English](benchmarks.md) · [返回首页](../README.zh-CN.md) · [算法原理](algorithm.zh-CN.md) · [基准脚本说明](../benchmarks/README.md)

本页汇总当前**单次因果区间扫描引擎**（`interval_credit.h` + `edit_alphabet.h`）在单线程 CPU 上的典型耗时、坐标压缩效果以及数值精度验证结果。

> **测量环境**：单核绑定 Intel Xeon Platinum 8573C（`OMP_NUM_THREADS=1`、`OPENBLAS_NUM_THREADS=1`），1 次预热 + 5 次交错计时取中位数。原生反向计时包含 NumPy 封装、内存分配与完整反向计算；PyTorch 完整步计时包含线性投影、因果前向、MSE 损失、反向传播与 SGD 更新。

## 1. 独立高斯随机输入反向耗时（$T = 8192$）

下表展示一阶（`"first"`）与二阶（`"second"`）精确反向在各打包位宽下的中位耗时，以及相较于仓库早期 $\widetilde{O}(T^{5/3})$ 次二次引擎的实测加速比：

| 打包位宽 $b$ | 一阶耗时 (ms) | 二阶耗时 (ms) | 相比早期次二次引擎加速比（一阶 / 二阶） |
|---|---:|---:|---:|
| 1 bit | 12.68 | 15.24 | 4.49× / 3.92× |
| 2 bits | 11.73 | 13.48 | 3.53× / 3.21× |
| 4 bits | 9.94 | 10.93 | 3.28× / 3.16× |
| 8 bits | 7.79 | 9.68 | 2.93× / 3.00× |
| 12 bits | 12.79 | 15.41 | 1.62× / 1.89× |
| 16 bits | 9.23 | 11.07 | 1.21× / 1.42× |
| 32 bits | 2.00 | 2.69 | 5.82× / 5.86× |
| 64 bits | 3.75 | 5.24 | 5.77× / 4.96× |

跨 96 组独立高斯样例（$T \in \{2048, 8192\}$、8 种位宽、3 个随机种子），几何平均加速比为 **2.91×**（96/96 全部更快）。在 $b \ge 24$ 时，因果坐标压缩效应非常显著：

| 序列长度 $T$ | 位宽 $b$ | 坐标压缩后保留行数（3 个随机种子实测） |
|---:|---:|---|
| 8192 | 8 / 16 | 8192, 8192, 8192（全量保留） |
| 8192 | 24 | 361, 284, 307 |
| 8192 | 32 | 9, 0, 0 |
| 8192 | 64 | 0, 0, 0 |

## 3. 结构化 / 极端输入表现（$T = 2048$）

为了避免只测随机输入掩盖退化情况，基准测试同时覆盖了 4 类结构化极端序列：

| 序列类型 | 一阶耗时 (ms) | 二阶耗时 (ms) | 特点与行为说明 |
|---|---:|---:|---|
| `unary`（全相同常量串，$b=8$） | 0.88 | 1.67 | 触发单连续段差分快速路径，线性 $O(Tb)$ 完成 |
| `near_fanout`（高扇出近邻，$b=8$） | 1.34 | 2.21 | 相比早期引擎快 **11.7×–19.5×** |
| `lagged_copy`（延迟复制，$b=64$） | 12.49 | 13.96 | 存在长精确匹配段，进入长行删除与后缀索引查询 |
| `periodic`（强周期串，$b=4$） | 16.19 | 19.56 | 强周期会产生较长倒排表，是区间扫描相对偏慢的输入类型 |

## 4. 正确性与数值精度核验

- **物理翻转对拍**：独立 C++ 因果 DP 对拍测试（[`tests/cpp/interval_credit.cpp`](../tests/cpp/interval_credit.cpp)）逐一核验了 **74,896 次真实单 bit 翻转**与 1,812 个前向行。
- **跨实现一致性**：在 680 组配对原生测试中，前向输出、联合 bit 编码以及 $V$/嵌入梯度均**逐字节完全一致**；$Q/K$ 综合相对 L2 数值误差上限为 **$9.52 \times 10^{-15}$**（纯 IEEE `float64` 结合律舍入）。
- **内存安全**：核心区间归约与 C 训练 ABI 均通过 AddressSanitizer（ASan）和 UndefinedBehaviorSanitizer（UBSan）检查。
